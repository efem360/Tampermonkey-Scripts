## Overview

efem360 Google CP is a Tampermonkey userscript that enhances Google Search with advanced query-building tools, search operators, precision filters, and integrated research utilities.

Instead of manually constructing complicated search expressions or switching between multiple websites, users can manage many search and research operations through a single floating panel.

### Key Highlights

- **Advanced Search Builder:** Create complex Google search queries using an organized interface.
- **Search Operators:** Combine supported Google operators and logical expressions.
- **Precision Filters:** Refine searches by domain, URL path, file type, excluded terms, dates, country, and language.
- **OSINT Research Tools:** Access search shortcuts and tools useful for open-source research.
- **Integrated Utilities:** Use translation, currency conversion, flight search, hotel search, and football-related search shortcuts.
- **Multilingual Interface:** Use the panel in more than 130 interface languages.
- **Search History:** Review supported operations and export records in CSV or TXT format.
- **Seamless Integration:** Access the panel directly from Google Search through a floating interface.

## 📌 About the Project

**efem360 Google CP** is a userscript that integrates directly into Google Search, bringing advanced search operators, query-building tools, filters, and various utility services together in a single control panel.

The primary goal of the project is to make Google searches easier to manage and to consolidate different search tools within a single interface.

Instead of manually writing complex Google search queries, users can build them using visual controls, preview queries in real time, and apply their preferred filters.

The project is more than just a Google search shortcut. It is a comprehensive browser panel that combines search, discovery, translation, currency conversion, flights, accommodation, history, and utility tools.

### Main Objectives

- Simplify Google search operations.
- Manage advanced search operators through a visual interface.
- Automatically build complex search queries.
- Control search filters from a single location.
- Provide quick access to different Google services.
- Combine utility tools within the same panel.
- Offer a multilingual user interface.
- Keep the user experience as simple and functional as possible.

# ✨ Features

## 1. Advanced Google Search

The core module of the panel allows users to build Google search queries using advanced operators.

Users can combine different search parameters, create queries through visual controls, and perform searches directly on Google.

### Supported Search Operators

| Operator | Description |
|---|---|
| `intitle:` | Search for words in page titles |
| `allintitle:` | Search for all specified words in page titles |
| `inurl:` | Search for words in URLs |
| `allinurl:` | Search for all specified words in URLs |
| `intext:` | Search for words in page content |
| `allintext:` | Search for all specified words in page content |
| `define:` | Search for a word or term definition |
| `source:` | Search within a specific news source |

Some operators are converted into the format supported by Google while the query is being built.

### Query Logic and Utility Functions

- Exact phrase search.
- OR operator.
- AROUND(3) proximity search.
- Wildcard (`*`) support.
- Query grouping.
- Combining multiple operators.
- Live query preview.

### Live Query Preview

Search parameters selected in the panel are displayed instantly in the generated query.

This allows users to:

- View the generated query before searching.
- Check active parameters.
- Track filters added to the query.
- Remove unwanted parameters.
- Easily review the final query.

The query-building interface is designed to make complex search combinations easier to understand.

# ⚙️ Technical Architecture

## 15. Runtime Environment

The project is a JavaScript-based Tampermonkey userscript that runs in the browser.

### Technologies Used

- JavaScript.
- HTML.
- CSS.
- Tampermonkey API.
- Google Search URLs.
- External HTTP requests.
- Browser storage APIs.

### Supported URLs

The userscript is configured to run on Google domains, including:

```text
*://www.google.com/*
*://www.google.com.tr/*
*://www.google.*/*
```

### Excluded Pages

- Google reCAPTCHA pages.
- Google access and verification warning pages.

### Duplicate Panel Prevention

The userscript includes checks that prevent execution inside iframes and prevent a second panel from being created on the same page.

The panel's root element is:

```text
#goai-root
```

This check helps prevent multiple instances of the panel from appearing on the same page.

## 17. Data Storage

The project uses browser and Tampermonkey storage mechanisms for different types of data.

### Tampermonkey Storage

The following mechanisms are used as the primary storage method:

```javascript
GM_getValue()
GM_setValue()
```

These mechanisms allow user settings to be stored.

### localStorage

Local storage is available as a fallback mechanism when Tampermonkey storage cannot be used.

### sessionStorage

Used for session state and history records.

Example key:

```text
goai_mini_v3
```

### Language Package Cache

Language packages can be stored using the following naming pattern:

```text
goai_ui_pack_<lang>
```

The user's interface language is also stored:

```text
goai_ui_language
```

**Important:** Different storage mechanisms have different lifetimes and behaviors. In particular, `sessionStorage` should not be considered permanent storage.

# 🔐 Privacy and Security

## 19. User Data

efem360 Google CP is a userscript that runs inside the browser.

User settings and history records are managed through the specified browser and Tampermonkey storage mechanisms.

The project description does not include a separate user account, centralized user database, or account system running on a project server.

### Data Sent to External Services

Some features require information entered by the user to be sent to the relevant external services.

Examples:

- Search queries are sent to Google for Google searches.
- Text entered for translation is sent to Google Translate.
- Currency data is retrieved from the selected data provider.
- IP information may be retrieved through external IP lookup services.

- Do not include sensitive information in search queries.
- Do not submit confidential text to the translation field.
- Review the privacy policies of external services.
- Do not install userscripts from untrusted sources.
- Review the source code before installing the userscript.

### Security Limitations

This project is not a security scanner, antivirus program, or network monitoring tool.

Displaying IP information does not mean that the project analyzes all network traffic generated by the user.

# 🛠️ Troubleshooting

## 22. The Panel Does Not Open

Check the following steps:

1. Make sure the Tampermonkey extension is installed.
2. Ensure that the userscript is enabled.
3. Refresh the Google Search page.
4. Check that the correct userscript version is installed.
5. Check the browser console for JavaScript errors.

## 23. Language Switching Does Not Work

1. Check your internet connection.
2. Make sure the language package can be loaded.
3. Refresh the page.
4. Check whether the selected language is supported.

## 24. Translation Does Not Work

1. Check access to the Google Translate service.
2. Check the source and target languages.
3. Try the translation again.
4. Check the browser console for errors.

## 25. Currency Data Is Not Displayed

1. Check your internet connection.
2. Change the selected data source.
3. Check whether the data service is accessible.
4. Try again later.

## 26. History Records Are Missing

Remember that history records are stored in `sessionStorage`.

Closing the browser session or clearing session data may cause records to disappear.
